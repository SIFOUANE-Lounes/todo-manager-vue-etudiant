# To-Do Manager

## 📝 Project Description
This project is a simple **To-Do Manager** made with **Vue 3** and **TypeScript**.  
It allows the user to add, delete, and update tasks easily.  
All data is saved in the browser using **localStorage**, so the tasks stay after a refresh.

## ⚙️ Technologies Used
- Vue.js 3  
- TypeScript  
- Vite  
- HTML / CSS  
- localStorage
